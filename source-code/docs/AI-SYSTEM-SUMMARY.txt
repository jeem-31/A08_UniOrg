═══════════════════════════════════════════════════════════════════════════════
                        KEY INFORMATION EXTRACTION RULES
═══════════════════════════════════════════════════════════════════════════════

ORGANIZATION NAME:
- Pattern: /organization[:\s]+([A-Z][A-Za-z\s&]+)/i
- Pattern: /([A-Z][A-Za-z\s&]+)\s+Organization/i
- Pattern: /Student\s+Organization[:\s]+([A-Z][A-Za-z\s&]+)/i

SCHOOL YEAR:
- Pattern: /S\.?Y\.?\s*(\d{4}[-–]\d{4})/i
- Pattern: /School\s+Year[:\s]+(\d{4}[-–]\d{4})/i
- Pattern: /Academic\s+Year[:\s]+(\d{4}[-–]\d{4})/i

SEMESTER:
- Pattern: /(First|Second|Summer|1st|2nd)\s+Semester/i

DATE:
- Pattern: /Date[:\s]+([A-Za-z]+\s+\d{1,2},?\s+\d{4})/i
- Pattern: /(\d{1,2}\/\d{1,2}\/\d{4})/
- Pattern: /([A-Za-z]+\s+\d{1,2},?\s+\d{4})/

AMOUNT (Financial):
- Pattern: /(?:PHP|₱|Php)\s*[\d,]+\.?\d*/
- Pattern: /Total[:\s]+(?:PHP|₱)?\s*[\d,]+\.?\d*/i

PRESIDENT:
- Pattern: /President[:\s]+([A-Z][a-z]+(?:\s+[A-Z][a-z]+)+)/i

ADVISER:
- Pattern: /Adviser[:\s]+([A-Z][a-z]+(?:\s+[A-Z][a-z]+)+)/i

                        AUTO-TAGGING RULES

TAG GENERATION PRIORITY:

1. DOCUMENT TYPE (Always included)

   - First Semester
   - Second Semester
   - Summer

5. FINANCIAL KEYWORDS (For financial docs)
   - Budget
   - Expenses
   - Income
   - Financial

6. ACTIVITY KEYWORDS (For activity docs)
   - Activities
   - Events
   - Programs

7. ACADEMIC KEYWORDS
   - Academic
   - Student
   - Organization

TAG LIMITS:
- Maximum: 10 tags per document
- Minimum: 3 tags (document type + 2 others)
- Duplicates: Automatically removed

                        GOOGLE CLOUD PROCESSING
═══════════════════════════════════════════════════════════════════════════════

📂 File: app/Services/GoogleCloudVisionService.php
📂 File: app/Services/GoogleCloudNLPService.php

SERVICES USED:

1. GOOGLE CLOUD VISION
   - Document Text Detection (OCR)
   - High accuracy (98%+)
   - Handles handwriting
   - Multi-language support
   - Confidence Score: 0-100% (converted from 0.0-1.0 decimal)

2. GOOGLE CLOUD NATURAL LANGUAGE (PRIMARY FOR AUTO-TAGGING)
   - Entity extraction (PRIMARY USE)
   - Sentiment analysis
   - Syntax analysis
   - Content classification

ENTITY TYPES EXTRACTED:
- PERSON (Type 1) - Names of people
- LOCATION (Type 2) - Places, addresses
- ORGANIZATION (Type 3) - Institutions, org names (PRIORITIZED FOR TAGS)
- EVENT (Type 4) - Activities, events
- WORK_OF_ART (Type 5)
- CONSUMER_GOOD (Type 6)
- OTHER (Type 7)

SALIENCE THRESHOLD: 0.1
- Only entities with salience > 0.1 are included
- Salience = importance/relevance score (0.0 to 1.0)
- Higher salience = more important to document

AUTO-TAGGING FLOW WITH NLP:
1. Google Cloud Vision extracts text (OCR)
2. Google Cloud NLP extracts entities from text
3. Gemini analyzes document and generates AI tags
4. Tags combined using priority system:
   - Priority 1: AI-generated tags from Gemini (MAIN)
   - Priority 2: Document type
   - Priority 3: Organization name
   - Priority 4: School year
   - Priority 5: High-salience entities from NLP (salience > 0.1)
5. Final tags limited to 10 maximum

ENTITY FILTERING FOR TAGS:
- Organizations (Type 3) prioritized
- Generic entities filtered out (e.g., "Republic", "Province", "OFFICE")
- Duplicates removed automatically
- Only adds entities if less than 8 tags already
