═══════════════════════════════════════════════════════════════════════════════
                    📊 SALIENCE SCORE EXPLAINED
═══════════════════════════════════════════════════════════════════════════════

Salience = Importance/Relevance Score (0.0 to 1.0)

0.0 - 0.05  → Very Low Importance (IGNORED)
0.05 - 0.1  → Low Importance (IGNORED)
0.1 - 0.2   → Medium Importance (INCLUDED if space available)
0.2 - 0.5   → High Importance (PRIORITIZED)
0.5 - 1.0   → Very High Importance (ALWAYS INCLUDED)

Example:

│ Salience: 0.35 (High Importance)                                            │

│ ✅ INCLUDED as tag                                                           │

                    📂 CODE LOCATIONS
═══════════════════════════════════════════════════════════════════════════════

1. NLP SERVICE (Entity Extraction)
   📄 app/Services/GoogleCloudNLPService.php
   
   Key Methods:
   - extractEntities($text)      → Extract entities from text
   - analyzeSentiment($text)     → Analyze sentiment
   - classifyText($text)         → Classify into categories
   - analyzeSyntax($text)        → Parse syntax

2. DOCUMENT PROCESSOR (Auto-Tagging Logic)
   📄 app/Http/Controllers/Osas/DocumentProcessorController.php
   
   Key Methods:
   - processWithGoogleCloud()    → Main processing flow
   - generateTagsFromGemini()    → Tag generation with priority system
   - extractKeyInfoFromGemini()  → Extract key information

3. TAG GENERATION LOGIC
   📄 app/Http/Controllers/Osas/DocumentProcessorController.php
   
   Method: generateTagsFromGemini($geminiResult, $entities)
   
   Lines: ~740-790
   
   Priority System:
   1. AI tags from Vertex AI
   2. Document type
   3. Organization name
   4. School year
   5. NLP entities (salience > 0.1)

                    ❓ FREQUENTLY ASKED QUESTIONS
═══════════════════════════════════════════════════════════════════════════════

Q: Paano ko i-enable ang Natural Language API?
A: Set GOOGLE_CLOUD_NLP_ENABLED=true sa .env file

Q: Bakit walang entities na na-extract?
A: Check if:
   - GOOGLE_CLOUD_NLP_ENABLED=true
   - credentials.json file exists
   - Text has meaningful content (not just images)

Q: Paano ko ma-adjust ang salience threshold?
A: Edit line ~770 in DocumentProcessorController.php:
   if ($entity['salience'] > 0.1)  // Change 0.1 to your desired threshold

Q: Ilang tags ang maximum?
A: Maximum 10 tags per document (configurable in code)

Q: Ano ang difference ng AI tags vs NLP entities?
A: - AI tags: Generated by Vertex AI (intelligent, context-aware)
   - NLP entities: Extracted by Natural Language API (factual, name-based)
   - Both are combined for best results

Q: Pwede ba akong gumamit ng NLP lang without AI?
A: Yes, pero mas maganda ang results with AI. NLP provides entities,
   AI provides context and intelligent tagging.
