Opaque masks are baked into lossless WebP pixels; there is no recoverable hidden original in the delivered image. EXIF and ICC metadata are omitted. Original images remain unchanged and are not packaged. Exact input/output hashes, dimensions and mask rectangles are in manifest.json; scripts/prepare_research.py records the process.

Interface totals, dates, filenames and amounts are screenshot content, not research findings. These historical research screens do not establish the current deployment state or prove that every screen matches the latest code revision. The website reports actual study results separately, with manuscript table references.

Private profile/COR/payment-receipt screens, member lists, candidate photos and signed documents were not selected for this gallery.
