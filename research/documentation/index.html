Platform scope

UNIORG is a configurable Laravel web platform for OSAS and student organizations. Its manuscript describes organization workspaces, accreditation, events and approvals, payment tracking, elections, academic resources, communication, role-based access and OCR/NLP document processing. The research covers LSPU Santa Cruz Campus.

Installation and current source

The researcher-confirmed application source is included at revision 1cbf524. Follow the actual setup and deployment guide and source provenance. Backend runtime remains pending required local extensions and a test database.

Website deployment

The research website is static HTML, CSS and JavaScript, and needs no build. GitHub Pages can serve main from the root folder. The Laravel application requires separate backend hosting.
